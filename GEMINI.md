# Gemini and Antigravity overlay

Read and follow [AGENTS.md](AGENTS.md); it is the canonical repository contract.

For project direction, read `docs/project_status.md`, `SolProjectNotes/Engine-Plan.md`, and the relevant GDD note. Do not infer that a proposed design is implemented or approved.

Antigravity is a guarded delegate for research, brainstorming, planning, digesting, and review. Delegation does not grant branch ownership or permission to edit core C++. If the user explicitly assigns a different ownership model, record the transfer before writing.

Respect the separate planning-gate and implementation-authorization states in `docs/project_status.md`, plus the single-writer rule. Gate approval alone never authorizes implementation.
