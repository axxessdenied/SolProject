The Stars Don't Wait

This game is built on a from-scratch engine. Almost everything in it - the
math, the ECS, the containers and allocators, the asset formats, the mesh and
image importers, the platform layer, the audio mixer, the UI - is written in
this project's own repository and is covered by the LICENSE file beside this
one.

Two third-party libraries are compiled into the game executable. Both are MIT
licensed, and both licences require this notice to accompany the binary. Their
full texts follow.

Not listed here, deliberately: stb_vorbis. It decodes Ogg Vorbis, and it is
linked ONLY into the asset cooker, which is a build tool and is not part of
this distribution. Audio is decoded to PCM when the game is built, so the
shipping binary carries no audio decoder at all. That was a design decision
rather than an accident; this shorter notice is what it bought.
